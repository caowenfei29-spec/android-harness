# 技能：信息流摘要（FEED_SUMMARY）

目标：浏览 N 条信息流内容（抖音/快手/微博等）并逐条总结。

流程：
1. launch 目标 App，确认目标 Tab
2. 每条：截图 + OCR 读取画面字幕/标题（关键：视频标题在渲染层，
   uiautomator 读不到，必须用截图 OCR 读取画面文字）
3. 逐条记录主题/标题/作者（可见才写）
4. 上滑下一条，直到 N 条
5. 汇总 1..N

关键实现：
- 感知层提供 screen_ocr()：截图 + 中文 OCR，返回画面可见文字
- 每条视频用 get_state 拿前台包名 + screen_ocr 拿标题/字幕
- 计数靠"已记录条数"，不要无脑滑

默认：
- 不点赞、不评论、不关注、不分享（除非用户明确要求）
- 广告/直播单独标注
- 内容卡住则改变滑动参数；仍失败则 failed
