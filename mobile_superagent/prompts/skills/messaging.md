# 技能：消息发送（MESSAGING）

必需信息：联系人（精确）、消息内容。缺失先问清，不臆测。

流程：
1. launch 消息 App（默认微信 com.tencent.mm，未装则 failed 说明）
2. 确认登录态与账号
3. 搜索并进入会话（搜索优先于盲滑）
4. 强校验会话标题/对象就是目标联系人（看 UI 文字）
5. 输入内容（input_text clear=true submit=false；中文用 type_unicode）
6. tap 发送
7. 校验出现已发送消息证据
8. 成功后停止，绝不再重发

安全：
- 对象不确定不发送；不连点发送；未验证成功不高频重试
- 出现风控/验证/登录失效立即 takeover
- 不群发、不转账、不删聊
